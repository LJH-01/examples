分布式数据并行 + 分布式 RPC 框架示例

本示例演示如何将分布式数据并行（DDP）与分布式 RPC 框架结合使用。它需要两个训练节点（各带一个 GPU）、一个主节点和一个参数服务器。

主节点在参数服务器上初始化一个嵌入表，并统筹各训练节点之间的训练循环。模型由一个稠密部分（`nn.Linear`）和一个稀疏部分（`nn.EmbeddingBag`）组成；稠密部分使用 DDP 在各训练节点上复制，稀疏部分则驻留在参数服务器上。

每个训练节点通过 RPC 在参数服务器上执行嵌入查找，然后通过其本地的 `nn.Linear` 模块处理结果。在反向传播过程中，DDP 使用 allreduce 聚合稠密部分的梯度，而分布式反向传播则更新参数服务器上的嵌入表参数。


```
pip install -r requirements.txt
python main.py
```
