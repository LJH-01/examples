# 时间序列预测

这是一个供初学者入门的玩具示例。它有助于同时学习 PyTorch 和时间序列预测。本示例使用两个 LSTMCell 单元来学习一些从不同相位开始的正弦波信号。在学习正弦波之后，网络会尝试预测未来的信号值。结果如下图所示。

## 用法

```
python generate_sine_wave.py
python train.py
```

## 结果

图像中展示了初始信号和预测结果。我们首先给出一些初始信号（实线）。随后网络会给出一些预测结果（虚线）。由此可以得出结论：该网络能够生成新的正弦波。
